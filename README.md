# C4-D 本地大模型 Agent

EduSeed Elite20 挑战任务 **C4-D（本地大模型 Agent）** 交付物仓库。

## 任务一句话

在**本地设备**（不经云端）跑通一个大模型，让「与 AI 协作」这件事不依赖网络，并产出可复核的运行证据 + 复盘 + 公众号文章。

## 技术栈与选型

- **设备**：Apple M5（MacBook Air，16 GB 统一内存，Metal 11.8 GiB VRAM）
- **运行方式**：Ollama v0.40.2（本地，mlx 加速，100% GPU）
- **模型**：`gemma4:e4b`（约 9.5 GB，量化 4-bit）

## 诚实说明

- 本地运行**不依赖国产模型**也能完成核心流程；本次选 `gemma4:e4b` 是出于「本机 16 GB 内存可跑 + 完整对话能力」的实测取舍。
- 截图由用户本人亲手截取（AI 调用系统截图受 macOS「屏幕录制」权限限制，无法代办），与 `ollama ps` 命令记录相互印证。
